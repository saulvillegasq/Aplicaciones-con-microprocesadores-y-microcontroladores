# Práctica 04 — Interrupciones GPIO

## Objetivos

- Comparar polling e interrupciones.
- Estudiar flancos.
- Comprender IRQ e ISR.
- Utilizar una bandera `volatile`.
- Mantener la ISR corta.
- Observar la latencia y el flujo evento → ISR → main.

Todavía no se corrige por completo el rebote; se observará su efecto sobre las interrupciones.
