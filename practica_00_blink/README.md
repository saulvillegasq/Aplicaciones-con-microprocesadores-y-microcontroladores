# Práctica 00 — Blink

## Objetivo

Construir, programar y ejecutar el primer firmware del curso.

## Conceptos

- `main()`

- GPIO de salida

- `sleep_ms()`
- compilación
- enlazado
- UF2
- BOOTSEL

Esta práctica es el equivalente embebido de un **Hola Mundo**.
