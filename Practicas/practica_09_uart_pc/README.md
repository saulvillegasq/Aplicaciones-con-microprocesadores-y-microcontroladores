# Práctica 10 — UART y comunicación con PC

## Objetivos

- Diferenciar UART y RS-232.
- Revisar TX, RX y GND.
- Comprender trama y baud rate.
- Enviar información del MCU hacia una PC.
- Reutilizar datos de prácticas anteriores, por ejemplo ADC.

## Punto clave

UART describe el periférico/protocolo lógico del MCU; RS-232 incluye además características eléctricas distintas.
