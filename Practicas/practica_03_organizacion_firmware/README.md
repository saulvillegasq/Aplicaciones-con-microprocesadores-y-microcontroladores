# Práctica 03 — Organización básica del firmware

## Objetivos

- Separar un programa que ya comenzó a crecer.
- Introducir `.c` y `.h`.
- Diferenciar interfaz e implementación.
- Introducir el concepto de driver.
- Mantener `main.c` como coordinador visible.

## Evolución

```text
main.c
  ↓
main.c + funciones
  ↓
main.c + módulos
```
