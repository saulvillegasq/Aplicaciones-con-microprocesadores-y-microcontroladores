# Práctica 06 — Temporizadores y código no bloqueante

## Objetivos

- Comparar NOP, espera activa y temporización por hardware.
- Revisar frecuencia, periodo y tick.
- Introducir alarmas y eventos temporales.
- Comparar código bloqueante y no bloqueante.
- Coordinar más de una actividad temporal.

## Actividad sugerida

- LED A cada 200 ms.
- LED B cada 750 ms.
- Sin encadenar `sleep_ms()` para controlar ambos.
